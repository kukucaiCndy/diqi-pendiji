## 0. 先看一个必须先解决的问题：字号

从设计稿实测的字号分布（`W7XDia` 全部 37 页统计）：

| 设计字号 | 出现次数 | 主要用途 |
| --- | --- | --- |
| 13px | 146 | **最常用的正文/说明** |
| 11px | 119 | 标记、星期字、微标签 |
| 12px | 72 | 卡标题、副文 |
| 14px | 67 | 区块标题 |
| 15px | 49 | 次级正文 |
| 10px | 42 | 最小标记 |
| 17px | 33 | 按钮文字 |
| 16px | 28 | 问候等正文 |
| 22 / 24 / 28 / 30 / 32 | 各 4–12 | 标题、关键数字 |

需求文档 §FR-15 原文：**「正文 ≥ 20sp，关键数字 ≥ 32sp」**。

把设计稿最常见的正文 13px 提到 20sp 需要 **×1.54**；那会让 30px 的主标题变成 46sp。
这不是"调一下"，是两种设计语言的取舍。**三种方案见文末「待你决定」第 1 条。**

## 3. 换算规则（需要你确认，确认后我逐页执行）

### 3.1 几何：1 设计 px = 1 dp

理由：设计画布 468 宽，本机 372dp。设计宽度几乎全是 `fill_container`（流式），
固定值只有图标/圆点/按钮高度。圆角 20、内边距 20、按钮高 52 这些**直接当 dp 用**，
FR-15 的「热区 ≥44dp」因此自动满足（52 ≥ 44）。**不做几何缩放。**

### 3.2 字号：三条待选路线（见下）

### 3.3 颜色：直接取 hex

设计变量 `ink #1A1A1A / brand #0F766E` 与页面内联色（`#0F1A24 / #5EEAD4 / #8FA3B8`）
并存。**以页面节点上的内联色为准**（那是最终效果），变量表仅作参考。
现有 `HrColor` 里 `Ink=#0F1A24`、`Accent=#5EEAD4`、`PanelTextMuted=#8FA3B8` 已与设计一致，
`Canvas=#F4F6F8`、`Warn=#B45309`、`WarnContainer=#FEF3C7`、`Good=#047857`、`Line=#E2E8F0` 也一致。
**颜色基本没问题，问题在结构与字号。**
