## 1. 一句话结论

应用可在 NX729J（Android 15）上完整走通 **无摄像头 → 引导筛查 → 训练 → 完成自评 → 记录 → 周报分享** 闭环；
真实心率链路因缺 FacePhys AAR 无法出数，但帧链路（CameraX→ML Kit→9×9×3 ROI→投喂）真实运行且**绝不伪造数值**。

## 5. 需要产品/临床确认的事项

1. **FacePhys AAR 与 AppKey** —— 唯一挡住真实心率的东西。
2. **训练参数默认值**（收缩/保持/放松各 5s、8 次）需临床签字；`planVersion` 已隔离，调参不破坏历史可追溯性。
3. **SQI 门限 0.50** 需真机标定。
4. **「清除数据」语义**：当前清业务数据、保留同意与筛查留痕（合规优先）。
5. **`DailyProgress` 采用派生实现**、**演示数据「落库+过滤」** 两个偏离裁定（见 `docs/AC-MATRIX.md`）。
6. **语音是 macOS 合成音**，正式版是否换真人录音（`VoiceScript` 单一来源，替换只换 assets）。
