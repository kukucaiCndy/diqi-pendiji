**恢复操作**：`设置 → 开发者选项 → 无线调试 → 开启`，确认端口仍是 `41015`。
若是新端口，告诉我新端口即可。

## 4. 唯一未达标的**非功能**指标：掉帧

| 阶段 | p90 | 掉帧比例 |
| --- | --- | --- |
| 原始（100ms 无条件推帧） | 34ms（543 帧） | 35.5% |
| 按显示签名去重（1 秒/次） | 61ms | 52.5% |
| + 拆状态流 + `PhaseTimeline` 收原语 | 48ms | 55% |
| + `LazyColumn` 按 item 增量测量 | 48ms | 54.8% |
| + 去掉重复的 36sp 倒计时 | **未测**（设备掉线） | — |

需求是 **< 5%**。已归因清楚：运行中每秒一帧、每帧约 48ms；暂停后 **0 帧 0 慢**，
所以是"单次重组太重"，不是帧率不足。

**剩余两步（已定位，未做）**：
1. 圆环改 `Modifier.drawBehind`，把文字移出 Canvas（只重绘弧线，不重排版文字）；
2. 必要时倒计时自绘（`TextMeasurer` 预测量 + 缓存）。

## 5. 需要产品/临床裁定的 6 件事

1. **演示模式的"全屏水印"**：FR-14 原文要求全屏水印，现在实际是**指标卡内一枚 chip**
   （`P04_DEMO_WATERMARK`，有测试）。接受 chip 就改判据，否则要加水印层。
2. **关闭演示模式是否删除演示记录**：现在会删（`deleteSimulated()`），
   与 FR-14「记录页以水印样式展示」冲突。统计侧已有 SQL 过滤，不删也不会污染。
3. **训练参数默认值**（收缩/保持/放松各 5s、8 次）需临床签字。`planVersion` 已隔离，调参不破坏历史。
4. **SQI 门限 0.50** 需真机标定。beta 阶段已按用户裁决改为**双门限**：
   显示下限 `floor = 0.30`（`< 0.30` 不出数字），达标门限仍 `0.50`，
   中间带 `[0.30, 0.50)` 出数字但常驻「信号一般，估算值仅供参考」（`DEGRADED`）。
   依据：实测室内 SQI 落在 0.15–0.49，0.50 单门限永不达标、演示看不到数。
   **回退条件**：正式发版前由临床签字，把 `floor` 改回 0.50（即 `floor == threshold`，
   中间带消失，其余逻辑一行不改）。
5. **「清除数据」语义**：现在清业务数据、保留同意与筛查留痕（合规优先）。
6. **语音是 macOS 合成音**：正式版是否换真人录音（`VoiceScript` 单一来源，换只换 assets）。
